# DESIGN.md — Emberglass

## Visual direction

- **Palette:** obsidian, oxidized iron, furnace orange, cobalt glass, dull brass, chalk labels.
- **Typography:** Georgia for human craft and restrained system sans/monospace for instrumentation.
- **Composition:** the workshop fills the frame; interface weight stays at the edges. One objective card, one compact control bench, one optional profile drawer.
- **Materials:** rough volcanic rock, soot-dark brick, worn wood, glowing translucent glass, modest polished brass.
- **Depth:** warm furnace foreground against cold moonlit workshop windows and a dark caldera rim.
- **Motion:** slow orbit, furnace breathing, drifting sparks, rotating glass and artisan gestures. Reduced-motion keeps only state-critical movement.
- **Avoid:** generic neon sci-fi, glassmorphism cards, fantasy HUD clutter, photoreal assets, asset-store inconsistency, and decorative controls.

## Interaction direction

Temperature, rotation, breath and tools all mutate one serializable simulation state. Three commissions ask for distinct silhouettes instead of repeating the same timing task. Failure is recoverable and explained as thermal stress, not a dead end.
